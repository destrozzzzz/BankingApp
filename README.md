# BankingApp

A simple Java-based banking application that allows users to manage their accounts, perform transactions, and simulate basic banking operations. Built with standard Java and structured for easy expansion and learning.

## 🚀 Features

- Create and manage bank accounts
- Deposit and withdraw funds
- View transaction history
- Basic console-based UI
- Organized project structure using `src/` and `pom.xml` (Maven)

## 🛠️ Tech Stack

- Java
- Maven
- Object-Oriented Programming (OOP)
- Git & GitHub for version control
